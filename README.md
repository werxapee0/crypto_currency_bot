# 🤖 Crypto & Currency Telegram Bot

Асинхронный Telegram-бот для мониторинга курсов мировых валют и криптовалют с умным калькулятором-конвертером прямо в чате.

> 💡 Бот создан для быстрого доступа к актуальным курсам без необходимости открывать браузер или банковские приложения.

---

## 🚀 Возможности

### 📊 Интерактивные курсы валют
- Выбор базовой валюты через инлайн-кнопки (UZS, RUB, USD, EUR, CNY, KZT)
- Курсы пересчитываются динамически относительно выбранной валюты
- Кнопка «🔄 Обновить» обновляет данные прямо в сообщении без спама в чате
- Источники данных: **Центральный Банк РФ** (фиат) и **CoinGecko API** (крипта)

### 🪙 Курсы криптовалют
- Bitcoin (BTC), Ethereum (ETH), TON, Solana (SOL), Tether (USDT)
- Актуальные цены в USD с отметкой времени последнего обновления

### 🧮 Умный калькулятор-конвертер
- Понимает свободный текстовый ввод: `100 usd в uzs`, `500 cny в rub`, `0.05 btc в uzs`
- Поддерживает сленг и синонимы: «сум», «бакс», «юань», «биток», «эфир», «тенге»
- Кросс-конвертация: фиат ↔ фиат, крипта ↔ фиат, крипта ↔ крипта
- Полная валидация ввода с понятными сообщениями об ошибках

### ⚡ Производительность и надёжность
- **In-memory кэширование** (TTL 5 мин) — защита от Rate Limit API и мгновенные ответы
- **Асинхронная архитектура** — бот не блокируется при ожидании ответа от серверов
- **Graceful error handling** — ни один сбой сети не уронит бота

## 🛠 Стек технологий

| Технология | Назначение |
|---|---|
| **Python 3.10+** | Язык разработки |
| **Aiogram 3.x** | Асинхронный фреймворк для Telegram Bot API |
| **Aiohttp** | Асинхронные HTTP-запросы к внешним API |
| **Cachetools** | TTL-кэширование ответов API |
| **Regex** | Парсинг пользовательского ввода |
| **python-dotenv** | Безопасное хранение секретов |
