# Crypto Currency Bot

Telegram-бот для просмотра курсов валют и криптовалют и конвертации между ними. Я сделал его как учебный проект для практики асинхронного Python, работы с внешними API и обработки пользовательского ввода.

👉 **Ссылка на бота в Telegram:** [@ccurrencys_bot](https://t.me/ccurrencys_bot)

---

## Возможности

- **Курсы валют:** Просмотр курсов к выбранной валюте (UZS, RUB, USD, EUR, CNY, KZT).
- **Криптовалюты:** Просмотр актуальных цен BTC, ETH, TON, SOL, USDT.
- **Конвертация в чате:** Понимает обычные текстовые сообщения, например:
  - `100 usd в uzs`
  - `500 cny в rub`
  - `0.05 btc в uzs`
- **Поддержка сленга:** Понимает названия валют на русском языке (`сум`, `юань`, `тенге`, `биток`, `эфир`, `бакс`).
- **Защита от ошибок:** Подсказки при неверном формате команды или неизвестной валюте.
- **Навигация:** Удобные кнопки и обновление курса прямо в сообщении.

---

## Откуда берутся курсы

- **Фиатные валюты:** Бот получает данные через `cbr-xml-daily.ru` (сервис с данными ЦБ РФ). Курс за одну единицу рассчитывается с учётом номинала валюты.
- **Криптовалюты:** Бот запрашивает цены через **Binance API**. Если он недоступен, автоматически используется резервный **CryptoCompare API**. В расчётах используются полученные цены в USD (1 USDT принимается за 1 USD). Значения могут отличаться от курса покупки или продажи в конкретном банке или на бирже.
- **Кэширование:** Ответы API хранятся в памяти бота до **5 минут** (`cachetools`), чтобы не перегружать внешние сервисы заигрывающими запросами. Поэтому кнопка «Обновить» показывает свежий курс из кэша, если 5 минут ещё не прошло.

## Технологии

- **Python 3.10+**
- **aiogram 3.x** (асинхронная работа с Telegram API)
- **aiohttp** (асинхронные HTTP-запросы к API)
- **cachetools** (in-memory кэширование курсов)
- **python-dotenv** (управление переменными окружения)

## Запуск локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/crypto_currency_bot.git
   cd crypto_currency_bot
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   # Windows:
   python -m venv venv
   .\venv\Scripts\activate

   # Linux / macOS:
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Создайте файл `.env` в корне проекта:**
   Укажите ваш токен от [@BotFather](https://t.me/BotFather):
   ```env
   BOT_TOKEN=123456789:ВашТокенОтBotFather
   ```
   > ⚠️ **Важно:** не выкладывайте файл `.env` и ваш настоящий токен на GitHub.

5. **Запустите бота:**
   ```bash
   python main.py
   ```

> **Примечание:** Показывайте бота локально только при выключенном сервере на Render, иначе две копии с одним токеном будут конфликтовать (ошибка `getUpdates conflict`).

## Ограничения

- Бот поддерживает только перечисленный выше набор валют и криптовалют.
- Курсы зависят от доступности внешних API.
- Бесплатный хостинг (Render) может иметь ограничения по скорости и не гарантирует 100% непрерывную работу 24/7.
- Результаты конвертации носят исключительно справочный характер.
