# Crypto Currency Bot

Telegram-бот для просмотра курсов валют и криптовалют и конвертации между ними. Я сделал его как учебный проект для практики асинхронного Python, работы с внешними API и обработки пользовательского ввода.

## Возможности

- Просмотр курсов к выбранной валюте: UZS, RUB, USD, EUR, CNY или KZT.
- Просмотр цен BTC, ETH, TON, SOL и USDT.
- Конвертация сообщением в чате, например:
  - `100 usd в uzs`
  - `500 cny в rub`
  - `0.05 btc в uzs`
- Поддержка некоторых названий валют на русском языке, например `сум`, `юань`, `биток`.
- Подсказки при неверном формате или неизвестной валюте.
- Навигация с помощью кнопок.

## Откуда берутся курсы

Курсы обычных валют бот получает через `cbr-xml-daily.ru` — сервис, публикующий данные курсов ЦБ РФ. Курс за одну единицу рассчитывается с учётом поля `Nominal`.

Цены криптовалют бот запрашивает через Binance API; если он недоступен, используется CryptoCompare API. В расчётах используются полученные цены в USD. Значения могут отличаться от курса покупки или продажи в конкретном банке или на бирже.

Ответы API хранятся в памяти бота до **5 минут**, чтобы не отправлять одинаковый запрос при каждом нажатии. Поэтому кнопка «Обновить» не обязательно загружает новый курс, если кэш ещё действует.

## Запуск локально

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/werxapee0/crypto_currency_bot.git
   cd crypto_currency_bot
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

   Команды выше рассчитаны на Windows. В PyCharm также можно выбрать `.venv` как интерпретатор проекта.

3. Создайте файл `.env` в корне проекта:

   ```text
   BOT_TOKEN=сюда_вставьте_токен_от_BotFather
   ```

   Токен можно получить у [@BotFather](https://t.me/BotFather). **Не публикуйте `.env` и настоящий токен в GitHub.**

4. Запустите бота:

   ```bash
   .venv\Scripts\python main.py
   ```

Пока программа запущена на компьютере, бот отвечает на сообщения. Для работы на сервере необходимо отдельно развернуть приложение и задать там переменную окружения `BOT_TOKEN`. Не запускайте одновременно локальную и серверную копии с одним токеном при использовании polling — Telegram выдаст ошибку `getUpdates` conflict.

## Структура проекта

```text
main.py           Запуск бота
config.py         Чтение токена из переменных окружения
handlers.py       Сообщения, кнопки и конвертация
keyboards.py      Клавиатуры Telegram
services.py       Получение курсов и кэширование
requirements.txt  Зависимости
.env.example      Пример настройки токена
```

## Ограничения

- Бот поддерживает только перечисленные выше валюты и криптовалюты.
- Курсы зависят от доступности внешних API.
- Бесплатный хостинг может иметь ограничения и не гарантирует непрерывную работу.
- Результаты конвертации носят справочный характер и не являются финансовой рекомендацией.
